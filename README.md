# 亿航 EH216-S 全方位调研与分析

课程《飞行汽车技术基础》作业一。以可复现的证据链方法，分析 EH216-S 的技术可行性、应用场景与市场可行性。

## 核心结论

1. 竞争壁垒来自审定证据链，而非构型。
2. 参数把市场锁定在「体验」，不在「通勤」。
3. 订单规模成立，需求真实性尚未验证。
4. 跨过「能不能卖」，未跨过「能不能赚」。
5. 唯一能改写结论的变量是电池能量密度。

## 技术说明

纯静态站点，无构建步骤、无外部依赖、无 `fetch` 调用。

- 本地预览：双击 `index.html` 即可，无需启动服务器。
- 图表：全部为内联 SVG，随页面缩放，可打印。
- 样式：`assets/style.css`，响应式 + 打印样式。
- 脚本：`assets/main.js`，仅用于目录高亮。

## 部署

1. 新建 Public 仓库，例如 `eh216s-research`。
2. 将本目录全部文件放入仓库根目录（`index.html` 必须在根目录）。
3. Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main`，目录选 `/ (root)`，Save。
4. 约 1–2 分钟后访问 `https://tianba9.github.io/eh216s-research/`。
