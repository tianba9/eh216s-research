# 亿航 EH216-S 全方位调研与分析

以可复现的证据链方法，分析 EH216-S 的技术可行性、应用场景与市场可行性。

在线阅读：https://tianba9.github.io/eh216s-research/

## 核心结论

1. **竞争壁垒来自审定证据链，而非构型。** 全球唯一四证齐全；Joby 与 Archer 至 2026 年仍在取证流程中。
2. **参数把市场锁定在「体验」，不在「通勤」。** 30 km 航程、25 min 航时、120 min 补能，单机日架次约 3 班。
3. **订单规模成立，需求真实性尚未验证。** 客户以地方国资平台与金融租赁为主，多数意向订单未付定金。
4. **跨过「能不能卖」，未跨过「能不能赚」。** 2025 年营收 5.095 亿元、毛利率 62.0%、净亏损 2.31 亿元。
5. **唯一能改写结论的变量是电池能量密度。** 480 Wh/kg 电芯测试把航时推到 48 分钟，量产与否决定场景边界。

综合可行性评级：**B（有条件可行）**，条件见第 06 章。

## 三个可复算的定量结果

- **时间闭合**：2 + 18（30 km @ 90 km/h）+ 3 + 2 = 25 min，与公布航时严格吻合。
- **能量交叉验证**：质量预算反推电池 200 kg × 200 Wh/kg = 40 kWh；功率积分独立得 40.8 kWh。
- **单座成本**：固定成本 97.2 万元/年 ÷ 900 架次 ÷ 2 座 ≈ 556 元，与公开票价区间基本重合。
